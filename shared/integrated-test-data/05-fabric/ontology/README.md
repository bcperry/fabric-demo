# Ontology Guidance

Stage 06 should bind to governed Stage 03 Lakehouse products and Stage 04
Eventhouse tables rather than package examples. The minimum entity set is:

- Site
- System Instance
- Test Event
- Track
- Objective
- Finding
- Corrective Action

The ontology should link the delayed command event, the supporting range and
network evidence, the readiness limitation, and the corrective action so Fabric
IQ can explain the anomaly without blurring advisory evidence into human
authority.
