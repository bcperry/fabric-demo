# Agent Plan - Semantic Model and Reports

## Mission

Define the Direct Lake semantic model and customer-facing visual contract for the
integrated test and readiness story.

## Deliverables

- Model tables, relationships, formats, hidden technical columns, and descriptions.
- Measures for test objectives, track freshness/continuity, observed-versus-predicted
  timing, acknowledgement delay, readiness, data quality, and anomaly status.
- Report-page wireframes:
  1. Executive test overview
  2. Live test control
  3. Sensor-to-effector timeline
  4. Observed versus predicted
  5. Integrated readiness and sustainment
  6. Anomaly evidence
  7. Data trust and lineage
  8. Quick-look summary
- Audience-safe terminology and synthetic-data disclaimers.

## Acceptance

- Measures reconcile to Gold expected values.
- Drill-through retains run, scenario, track, system, and source lineage.
- No visual implies direct real-world fire-control behavior.
- Core 20-minute narrative works without Copilot or ontology.
- Static fallback pages preserve the same storyline.
