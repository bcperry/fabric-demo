# 05 - ML Models

Build readiness models from the same systems, operational snapshots, and
observations used by the prior stages. The workflow engineers features, compares
candidate models, records MLflow lineage, explains scores, performs governed
batch scoring, and monitors drift.

## Outcome

- **Leadership:** `Attention Now`, `Why This Ranking?`, and `Drift and Trust`
	answer what needs review, why, and whether the recommendation remains credible.
- **Data professionals:** reproducible feature engineering, train/test controls,
	model comparison, MLflow, explainability, scoring contracts, and drift metrics.

```bash
shared/setup-scripts/fabric_demo_cli.sh push-demo-05
shared/setup-scripts/fabric_demo_cli.sh run-demo-05
```

Scores prioritize human review. They never approve readiness, safety, or test
execution decisions.
